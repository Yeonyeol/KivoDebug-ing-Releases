- ‘선택한 카드’나 ‘현재 손패’만 할인해야 하는 효과가 ‘다음 아무 카드 무료’로 연결되는 버그

- 이벤트 전투 클리어 후, 휴식 노드에 가면 휴식 노드가 아니라 다른 게 나오는 버그
