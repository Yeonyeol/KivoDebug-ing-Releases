# KiVO Debug-ing

**Windows / Android 공개 배포 페이지**

Unity로 제작 중인 비공식 블루 아카이브 팬게임입니다. 이 저장소에서는 플레이어를 위한 게임 배포 파일, 업데이트 내용, 설치 안내와 알려진 문제를 제공합니다. 개발 소스와 작업 중인 프로젝트는 공개하지 않습니다.

v0.2.8에는 보급 노드 추가, 글리치 심도, 타격 피드백 개선 및 게임 수정이 포함되어 있습니다. 세부 내용과 검증 범위는 [v0.2.8 릴리스 노트](https://github.com/Yeonyeol/KivoDebug-ing-Releases/releases/tag/v0.2.8)를 확인하세요.

GitHub가 자동 표시하는 `Source code (zip)`과 `Source code (tar.gz)`는 이 공개 저장소의 문서 묶음이며 게임 설치 파일이 아닙니다. 위 링크 또는 릴리스 페이지의 **Assets**에서 Windows ZIP 또는 Android APK를 받으세요.

지원 환경, 저장 데이터 호환성, 설치 방법과 알려진 문제는 **받으려는 버전의 릴리스 노트**를 기준으로 합니다. 게임 저장 데이터를 지우거나 기존 Android 앱을 삭제하기 전에 해당 버전의 업데이트 주의사항을 확인하세요.

## 업데이트 방침

- 개발 중인 수정과 개인 백업은 공개 배포에 자동 반영하지 않습니다.
- 규모가 큰 업데이트를 묶고, 개발자가 공개 배포를 결정한 버전만 게시합니다.
- 커밋, 푸시, 병합 또는 개발 버전 변경만으로 게임 배포본을 게시하지 않습니다.
- 게임 ZIP / APK는 저장소의 코드 파일이 아니라 **GitHub Releases 첨부 파일**로 제공합니다.

배포 안내 문서의 수정과 새 게임 버전 공개는 별개입니다. 문서가 갱신되어도 다운로드 파일은 달라지지 않을 수 있습니다.

게임 버전, Windows / Android 구분, 재현 과정, 예상 동작과 실제 동작을 적어 주세요. 로그나 화면에 개인정보, 계정 정보, 인증 토큰 등이 있다면 제거한 뒤 첨부해 주세요. 공개 이슈에는 누구나 접근할 수 있습니다.

## 비공식 팬게임 안내

이 프로젝트는 블루 아카이브의 공식 게임이나 공식 배포물이 아니며, 원작의 제작사 및 권리자와 제휴한 프로젝트가 아닙니다. 원작과 관련된 명칭 및 권리는 각 권리자에게 있습니다.
