# KiVO Debug-ing

>>이 프로젝트는 블루 아카이브의 공식 게임이나 공식 배포물이 아니며, 원작의 제작사 및 권리자와 제휴한 프로젝트가 아닙니다. 원작과 관련된 명칭 및 권리는 각 권리자에게 있습니다.

> Unity로 제작 중인 비공식 블루 아카이브 팬게임입니다.
> 이 페이지는 배포용이며 게임 배포 파일, 업데이트 내용, 설치 안내와 알려진 문제를 제공합니다.

> 이 프로젝트는 ChatGPT, Codex의 도움을 받았습니다.
