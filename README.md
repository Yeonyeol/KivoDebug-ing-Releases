# KiVO Debug-ing
가칭 블더스.

[ 이 프로젝트는 블루 아카이브의 공식 게임이나 공식 배포물이 아니며, 원작과 관련된 명칭 및 권리는 각 권리자, 넥슨 및 요스타에게 있습니다. ]

> Unity로 제작 중인 비공식 블루 아카이브 팬게임입니다.
> 이 페이지는 배포용이며 게임 배포 파일, 업데이트 내용, 설치 안내와 알려진 문제를 제공합니다.

> 이 프로젝트는 ChatGPT, Codex의 도움을 받았습니다.

## 업데이트 방침
* 다음 대규모 업데이트 시(일정 미정)
- 플레이어블 학생 [케이] 추가 예정.
- 신규 보스 [시로코*테러] 추가 예정.
- 글리치 존은 심도 고층(7 이상) 전용(4스테이지)으로 변경(보스 고정)
- 3스테이지 기본 배경 [D.U(시로코 테러, 와카모, 페로로지라 할당)], [강철대륙(게부라, 호크마, 티페레트 할당)] 추가 예정.
- [게헨나]는 추가는 하고 싶은데 관련 아이디어가 없음.


* 소규모 업데이트 시
- 버그 수정.
